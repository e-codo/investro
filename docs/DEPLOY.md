# Деплой на Vercel

Состояние на сегодня: в репозитории `e-codo/investro` лежат ТЗ, кликабельный макет и шаблон таблицы. Самого приложения (Next.js, база, вход, разбор отчётов) ещё нет, поэтому задеплоить можно только макет. Инструкция для приложения ниже тоже есть, но она заготовка: её надо сверить, когда появится код.

## Вариант 1. Макет как статическая страница (можно сделать сегодня)

Это не рабочий сервис: данные примера зашиты в страницу, ничего не сохраняется, вход и загрузка отчёта имитируются. Подойдёт, чтобы показать макет по обычной ссылке.

Перед началом: на странице реальные цифры вашего портфеля (отчёты за август–октябрь), и адрес будет открыт всем, у кого есть ссылка. Если это не подходит, не публикуйте или включите защиту паролем в Settings → Deployment Protection (на тарифе Hobby защита может быть недоступна, проверьте в настройках).

1. Зайдите на vercel.com, войдите через GitHub (бесплатного тарифа Hobby достаточно).
2. Add New → Project → выберите репозиторий `e-codo/investro`. Если репозитория нет в списке, нажмите «Adjust GitHub App Permissions» и дайте доступ к нему.
3. Ветка: макет лежит в ветке `claude/wonderful-sagan-hg144x`. Либо смержите её в `main`, либо в Settings → Git задайте Production Branch этой ветке.
4. Настройки сборки: Framework Preset — Other, Build Command и Install Command пустые, Output Directory — `.` (точка). Файл `vercel.json` в корне уже направляет `/` на `docs/preview.html` и просит поисковики не индексировать сайт.
5. Нажмите Deploy. Через минуту откроется адрес вида `https://investro-….vercel.app` с макетом.

Что не работает на статической версии: настоящий вход и сохранение данных, загрузка и разбор файлов, скачивание шаблона по кнопке (файл лежит по адресу `/docs/template-report.xlsx`).

## Вариант 2. Приложение (после того, как будет написан код)

Основа взята из деплоя старого проекта `e-codo/invest`. Отличия нового: нет Мосбиржи и ежедневного обновления (cron не нужен), нет `APP_PASSWORD`.

1. **Код.** Vercel выпускает в продакшн ветку `main`.
2. **Проект.** Add New → Project → репозиторий `e-codo/investro`. Framework Preset: Next.js. В `package.json` должна быть команда `vercel-build`: `drizzle-kit migrate && next build`.
3. **База.** Storage → Create Database → Neon (Postgres) → подключить к проекту. Vercel сам добавит `DATABASE_URL` и `DATABASE_URL_UNPOOLED`. Делайте это до первого деплоя, иначе миграция упадёт.
4. **Переменные окружения** (Settings → Environment Variables), для Production: `SESSION_SECRET` — случайная строка не короче 32 символов (`openssl rand -base64 48`). Без неё приложение не стартует.
5. **Deploy.** Откройте адрес проекта и создайте аккаунт (регистрация открытая, раздел 7.1 ТЗ).

Советы:
- Регион функций (Settings → Functions) лучше выбрать тот же, что у базы Neon.
- Базу подключайте только к Production, чтобы Preview-сборки не писали в боевые данные.
- Загрузка отчётов идёт целиком в браузере, на сервер уходят только распознанные числа, поэтому лимиты размера запроса Vercel не мешают.
- Резервные копии: посмотрите в настройках Neon, за какой срок можно восстановить данные.

Чек-лист после деплоя: регистрация и вход работают; повторный вход после выхода; загрузка сентябрьского отчёта даёт стоимость 36 237,86 ₽ и взнос 18 000 ₽; отчёт с началом года отклоняется; в Neon появились таблицы.
